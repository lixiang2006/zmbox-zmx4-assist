# Contributing

Please keep changes Windows 10 22H2+/Windows 11 compatible, dependency-light,
and free of injection, drivers, anti-detection, or rule-bypass mechanisms.
Run `dotnet test ZmboxZmx4Assist.sln -c Release` before opening a pull request.
Never commit game assets, launcher binaries, account data, macros, or files from
`%LOCALAPPDATA%`.
