# Zmbox ZMX4 Assist

## Agent skills

### Issue tracker

Issues and specs live as GitHub issues in `lixiang2006/zmbox-zmx4-assist`, managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical triage roles, each label string equal to its role name (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

single-context — one `GLOSSARY.md` at the repo root plus architecture decisions in `docs/adr/`. See `docs/agents/domain.md`.
