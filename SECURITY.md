# Security policy

Do not open public issues for a vulnerability that can cause unintended input,
data disclosure, or unsafe file handling. Use GitHub's private vulnerability
report form at
https://github.com/lixiang2006/zmbox-zmx4-assist/security/advisories/new
with reproduction steps and a harmless proof of concept.

This project does not accept features intended to bypass anti-cheat, launcher,
or platform restrictions.
